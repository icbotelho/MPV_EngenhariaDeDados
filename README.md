# MPV_EngenhariaDeDados
Projeto Acadêmico MVP: Construção de um Pipeline usando Databricks 

Ponto de partida:

Explorar a base do censo demográfico de 2022.

Objetivo do MVP:
O objetivo é mapear os setores censitários do Estado do Rio de Janeiro e buscar uma correlação entre os indicadores socioeconômicos disponíveis. Para isso será necessário desenvolver um pipeline da dados que envolva captura de dados, o cruzamento de diferentes tabelas da fonte escolhida, tratamento relacional entre as origens, criação de camadas de consulta e análise dos dados obtidos.

Fonte escolhida: ibge_censo_2022

Link/referência da fonte:
https://console.cloud.google.com/bigquery?ws=!1m4!1m3!3m2!1sbasedosdados!2sbr_ibge_censo_2022

Descrição/contexto dos dados:

Informações do censo demográfico de 2022 disponibilizadas através de um banco de dados no Google Cloud por uma organização não-governamental sem fins lucrativos e open-source que atua para universalizar
o acesso a dados chamada “Base dos Dados”.
